# US-2.1: Confirm Booking

## User Story
As a vendor integrator,
I want to confirm a booking through one endpoint,
So that booking is provider-agnostic for my team.

## Acceptance Criteria
1. Endpoint `confirm-booking` is available and documented.
2. Provider-specific logic is hidden behind unified response.

## Notes
- Target endpoint: `POST /api/hotels/confirm-booking`.
